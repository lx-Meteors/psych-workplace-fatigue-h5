# Visual Styles（视觉风格库 / 用于 3-Solution Proposal）

用这个库来写 `Stage Gate：3-Solution Proposal`（A/B/C）。每个风格都给了：
- **Traits（气质）**
- **Good for（适用主题）**
- **UI cues（具体 UI 元素提示）**

## NetEase Media（网易传媒感 / editorial）
- **Traits**：强层级排版（大标题/副标题/信息块）、模块化卡片（modular cards）、低饱和但高级（restrained saturation）
- **Good for**：职场/洞察/资讯专题型心理测试
- **UI cues**：
  - 大标题 + 小胶囊 badge（pill）
  - 信息卡（glassmorphism + soft shadow）
  - stepper + progress bar（强“流程感”）
  - 数据块/雷达/条形图（增强“可信感”）
  - 角标贴纸（“热度/趋势/标签”）

## Playful Meme（搞笑贴纸 / meme）
- **Traits**：梗标题、夸张标签、对比更强、节奏更快
- **Good for**：关系/情感/社交刷屏活动
- **UI cues**：贴纸角标、金句 punchline、更强按钮反馈（press/scale-down）、“吐槽卡片”

## Premium Minimal（高级极简 / premium minimal）
- **Traits**：留白大、阴影轻、视觉噪音低
- **Good for**：生活方式/人格洞察/高级调性
- **UI cues**：浅阴影卡面、细分割线、mono 指标、克制的色块点缀

## Pixel Retro（像素复古 / pixel）
- **Traits**：像素栅格、游戏关卡感（game-like）
- **Good for**：怀旧/校园/游戏向主题
- **UI cues**：像素边框、关卡 stepper、街机 CTA、像素徽章 chips

## Gradient Dreamy（梦幻渐变 / dreamy）
- **Traits**：流体渐变、柔光、氛围感强
- **Good for**：情绪/氛围/恋爱向主题
- **UI cues**：多层渐变背景、漂浮光斑 blobs、发光 badge、柔和过渡动效

## Palette Mapping Rule（配色映射规则）
- `primary`：CTA / progress / active state
- `secondary`：标题/正文主色、深色信息块、分隔线
- `accent`：徽章、强调点、匹配度/热度高亮
- `background`：全局底色 + 海报底色（poster base）
