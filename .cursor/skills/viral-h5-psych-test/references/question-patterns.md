# Question Patterns（题型模式库 / Scene-based）

目标：写出“微型情景剧”题干 + 可直接选择的行为选项（scene-based + behavior-based）。
禁止：抽象人格形容词、是/否题、同意/不同意。

## Scene Trigger（情境触发）
- **Pattern**："当...时，你会..."
- **Example**："当项目被临时改需求时，你第一反应是..."
- **Use for**：通用开场题、态度/习惯类

## Forced Trade-off（强制取舍）
- **Pattern**："如果只能选一个，你会..."
- **Rule**：两边都要“看起来合理”，不能出现“明显更正确/更道德”的选项

## Social Snapshot（团队快照）
- **Pattern**："在团队里，你通常是..."
- **Rule**：选项必须落到不同协作行为（推进/洞察/连接/执行等），而不是抽象标签

## Stress Response（压力响应）
- **Pattern**："面对截止时间逼近，你会..."
- **Rule**：选项要能映射到规划/行动/协调/恢复等不同信号

## Symbol Metaphor（隐喻映射）
- **Pattern**："如果你是一种角色/工具，你会是..."
- **Rule**：隐喻必须能回到真实行为（避免纯脑洞无映射）

## Option Rules（选项硬规则 / Must Pass）
- 默认 **4 选项/题**
- **长度相近 + 吸引力相近**（别让人一眼选“最正常”）
- **动词开头/动作落地**：用“我会…”描述可执行行为
- 禁止是/否、同意/不同意
- 每个选项必须有清晰映射：`scores`（type/dimension）或 `resultId`

## 快速自检（Rewrite Trigger）
如果出现任意一条，整题重写：
- 选项读起来像“性格测试题库模板”
- 选项只有态度没有行为（例如“我更理性”）
- 选项明显褒贬（道德评判）
