# 视觉风格库

H5 心理测试的视觉风格参考。

## 可爱插画风

**特点：**
- 圆润的线条和形状
- 柔和的色彩过渡
- 卡通化的人物/动物形象
- 手绘质感

**适用主题：**
- 宠物测试（你是什么猫/狗）
- 食物测试（你是什么甜品）
- 性格测试（治愈系、萌系）

**技术要点：**
- 使用圆角（border-radius: 12px+）
- 柔和阴影（box-shadow 扩散值大）
- 手写体或圆体字体
- 漂浮的小装饰元素

## 极简现代风

**特点：**
- 大量留白
- 简洁的几何图形
- 高对比度配色
- 无衬线字体

**适用主题：**
- 职业测试
- 能力测试
- 生活方式测试

**技术要点：**
- 卡片式布局
- 细线条分隔
- 微交互动效
- 单色系或双色系

## 复古像素风

**特点：**
- 8-bit/16-bit 像素图形
- 复古配色（高饱和度）
- 像素字体
- 怀旧游戏元素

**适用主题：**
- 游戏角色测试
- 怀旧主题测试
- 亚文化测试

**技术要点：**
- 使用像素风图标
- 点阵字体
- 复古滤镜效果
- 游戏机 UI 元素

## 梦幻渐变风

**特点：**
- 流体渐变背景
- 玻璃拟态效果
- 发光元素
- 星空/宇宙元素

**适用主题：**
- 星座测试
- 灵性测试
- 艺术气质测试

**技术要点：**
- CSS 渐变动画
- backdrop-filter 模糊
- 粒子背景效果
- 霓虹发光文字

## 国潮风

**特点：**
- 中国传统元素
- 书法字体
- 水墨质感
- 红金配色

**适用主题：**
- 传统文化测试
- 古风角色测试
- 节日主题测试

**技术要点：**
- 中式纹样装饰
- 竖排文字排版
- 水墨晕染效果
- 印章元素

## 科技感风

**特点：**
- 深色背景
- 霓虹色点缀
- 网格/线条元素
- 数据可视化风格

**适用主题：**
- AI 相关测试
- 未来感测试
- 极客测试

**技术要点：**
- 深色主题（#0a0a0a 背景）
- 荧光色（cyan, magenta, lime）
- 等宽字体
- 扫描线效果

## 自然治愈风

**特点：**
- 大地色系
- 植物元素
- 水彩质感
- 手绘插画

**适用主题：**
- 植物测试
- 自然类型测试
- 生活方式测试

**技术要点：**
- 莫兰迪色系
- 叶子/花朵装饰
- 纸质纹理背景
- 手写体标题
